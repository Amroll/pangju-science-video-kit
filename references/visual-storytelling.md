# 胖橘的直观开头、行动与因果

新写脚本、加强开头或调整动作节奏时使用本文件。只改封面错字等局部工作不必重走脚本流程。这里将对标账号的制作特点转为本系列的写作方法，不要求每期检索账号，也不照抄其角色、台词或镜头。

## 1. 开头先写画面，再写台词

内部快速拟2—3个可行钩子，用一句画面描述比较，选一个写进成稿；不用把候选方案变成用户必批步骤。

优先从本题选择：
- 可见反差：同一对象在明确改变一个条件前后，或两个对象在可比较条件下，出现明显不同的结果；保留参照物，材料和条件必须支持对比。
- 行动受阻：胖橘要完成一件具体的事，眼前现象使目标受阻。
- 结果先到：直接看见与本题相关的意外结果，再揭示原因。
- 熟悉物体的内部：胖橘触发一个动作，画面随即显出内部正在发生什么。

用四个问题筛选：不听声音能看出关注点吗？与核心答案直接相关吗？后续能给出真实解释吗？单段10秒的动作复杂度可实现吗？只靠文字悬念、背景爆炸、猫突然瞪眼或圈内梗才成立的方案重写。结果先到并非每期必用，不能制造错误预期。

还要比较候选方案的吸引点：“物体动了”可以是科学证据，但不一定足以让这只猫有特点。优先把现象与一个静音可读的不寻常操作、角色后果或显著反差放在同一条因果线上。具体写出观众首先看到的怪事；“有爆点”“有科学狂人感”不算画面。首帧可以截在操作即将出结果的阶段，前约一秒就有动作变化；避免端坐、举起道具、等旁白说完才开始。用近景或中近景让猫的脸、操作点和关键道具占据主要画面，不让大块空桌面稀释小动作。时间是创作目标，不是流量保证。

成稿必须填清：
- 0秒首帧：关键对象、位置、动作阶段，以及已经可见的异常或参照状态；不要让静帧假装已经呈现尚未发生的两种结果。
- 可见变化：前态→作用/条件变化→后态。指出观众实际能辨认的位置、形变、接触、运动或状态差异；不只写“很用力”“很惊讶”。
- 时间与看点：前约1—2秒首先看见什么变化，首次结果何时出现，镜头怎样让作用点和差异足够清楚。
- 兑现与后续疑问：第一段10秒内给出哪项实质答案或证据，下一镜揭示哪个尚未解释的原因；不靠重复提问重新制造悬念。
- 收束：最终结果如何回答开场同一个问题。

对于能迅速发生、且符合科学过程的反差，优先在前约2—3秒呈现两种可辨认的结果。过程较慢或必须保留操作步骤时，可从已有结果或同屏对照进入，再展示原因；不强迫所有题目在两秒内完成机制。0—2秒是创作检查点，不是算法规律或完播保证，也不要求每期都套“失败→成功”。

开头检查时先忽略台词和装饰贴纸：能否具体指出关注对象、作用点和状态差异？例如吸盘题，“猫后仰、皱眉”只说明努力；“杯颈受拉而杯缘仍贴住玻璃→掀边后杯缘离板、整个杯体被拿起”才给出可见反差。表情可辅助，但不能替代物体变化。脚本中找不到差异就先改写；生成图片不能约束清楚时调整景别或姿势。用户提供成片后再核查实际变化，不能因提示词写过就声称已经实现。

## 2. 猫的动作要有目标、作用点和结果

先写猫想完成的事，再写肢体。主要行动采用：

```text
目标：胖橘要{具体目标}。
动作：{猫自身左/右前爪或身体部位}，从{起始位置}向{方向}作用于{对象/接触点}。
过程：{对象如何受力/运动，或条件如何变化}。
结果：{道具状态、位置或局面可见地改变}。
反应：胖橘因{刚发生的结果}，出现{重心、耳朵、尾巴或表情变化}，并进入{下一步}。
```

一个主要动作尽量只有一个目标和清楚的接触关系。利用圆胖体型、短爪与重心转移放大表演；把动作依次排开，避免同时多爪换手、转身和操作多个道具。没有知识作用、角色后果或有效笑点的动作不保留。

### 科学狂人的表演方式

默认胖橘一遇到可验证的问题就亢奋：操作果断、盯作用点、看到结果后得意过头，急着继续试。每段按需要挑一两种具体表演，不叠满所有动作：
- 实验时：已抓稳道具后立刻短促操作，身体前倾、目光紧跟接触处；不能一直摇道具却不实际作用。
- 发现时：由刚发生的结果触发一次明显的后仰、抬头、收爪或重心变化，随后接着验证，不停下来长笑。
- 较劲时：因为上一轮结果而改变一个条件再试；短暂过度认真、滑稽的指挥姿势或自信过头可以提供反差。

无厘头感可以来自“为一件小事投入过头”，也可以来自实验对猫造成的可见小后果。每期不强制炸毛、翻车或同一笑点。夸张猫的动作幅度和反应，保持道具受力、作用距离、变化方向和必要过程可信；实验中看不见的机制以明确示意呈现。头毛可以蓬松，头部仍只有两只耳朵；瞪眼仍各只有一个虹膜和瞳孔。讲机制时允许猫安静观察，把注意力交给变化，不要求全程乱动。

声音保留低沉圆润的识别感，语气改为急切、兴奋、短促有重音；可用一声有原因的“动了！”等反应接行动。不得用持续尖叫、长笑、口头禅或音量代替视觉看点，关键术语仍说清楚。

“举爪讲解，惊讶，再点头”不足以构成行动；可以改成“推动已摆好的安全道具→切到作用点→装置出现对应变化→猫据此调整下一次动作”。具体科学过程必须按本题核对，不把示例当万能场景。

不强制每镜都出现猫。原理特写可以暂时离开猫，但回到猫时应承接同一动作或结果。动作服务知识，不让配音讲一个机制、画面却让猫追无关道具。

## 3. 让原因经过画面到达结果

写一个核心因果链，并给每个环节分配镜号：

```text
A 起始状态 → B 哪个条件/动作改变 → C 可见的中间过程 → D 结果 → E 对本题的解释或应用
```

用普通人可辨认的变化表达C：路径、形状、位置、数量、速度或状态如何改变。看不见的机制可用剖面、透明化、微观放大、轨迹或简化模型；先交代它对应外部哪个部位，必要时回到外部结果。不要突然切到一幅与原道具对应关系不明的抽象图。

对比时尽量只变一个主要条件，保留参照物；不能让观众把其他变化误当原因。镜头从A直接跳到D、台词一句“因为原理如此”，不算展示过程。不能为让图更戏剧化而把“减少”画成完全阻挡、把长期变化画成瞬间规律。

静音检查只要求主要行动、作用关系与前后差异可读；抽象科学含义可以依赖配音，不强迫动画无声解释全部知识。示意与时间压缩在制作说明和后期标识中明确。

### 原理图与实物的对应

仅对需要剖面、透明化、局部放大或机制示意的镜头填写以下内容，并展开到所属10秒段提示词；普通实物动作不套用这组字段。

| 对应项 | 必须明确的内容 |
|---|---|
| 对应对象与观察区域 | 来自哪件实际道具、哪个部位；从哪里剖开或放大，机位怎样从外观进入内部 |
| 保留的结构与位置 | 用于辨认的轮廓、主要部件、接触面、内外区域和相对方向；改变机位时保留可追踪的地标 |
| 前后状态 | 承接实物当时的状态；内部哪个变化导致外部哪个结果；何时返回同一器材和结果 |
| 可简化与不可改变 | 可以简化材质、纹理和非关键部件，不能改变密封/开口、相连/隔断等决定因果的关系 |
| 图示的含义 | 粒子或箭头分别表示物质移动、受力还是其他量；写清起点、方向、作用对象和随过程的变化，不能用同一未说明符号混指不同含义 |

剖切或透明化是观察方式，不是让实体真的裂开或新增通道。让“观察窗口”与真实开口可区分，不能把本应密封的装置画成实际敞口。例如吸盘剖面仍须对应拱形杯壁、玻璃表面及杯缘接触处；不能变成不相干的直壁盒子。进气路径走真实杯缘开口或接触间隙，不穿过完整杯壁；压力箭头与气流箭头分别说明含义。

不强求模型连续把3D道具变形成剖面。复杂时可从实物作用点切到轮廓、方向和接触关系对应的2D/2.5D简洁示意，再切回实物结果；保持既有示意标识约定。现有首尾图不足以约束关键结构时，按需补一张原理参考图，注明用途与对应镜号，不把它当作每期必交或额外的视频生成段。

若结果已变成另一件器材、丢失关键接触关系或画错路径，应修正；结构仍不稳定时简化机位、减少同时变化的元素，或改用明确匹配的示意切镜。不能只在提示词里加一句“科学准确”后继续交付。未生成对应图或未获得成片时，分别标明结构或动态过程尚待验证；这项检查不扩展为自动渲染或发布流程。

## 4. 提速靠更早发生变化

默认明快紧凑，省略不提供信息的取物、就位、复位、重复解释和长串场。讲解、动作与对应示意同步推进，同一时刻让观众关注同一件事。

以下是首个10秒段的可选预算，用于检查拖沓，不是固定镜头数或每段必须重复的结构：

| 局部时间 | 常用功能 |
|---|---|
| 0—约1.5秒 | 看点已经出现，明确关注对象 |
| 约1.5—4秒 | 猫行动或条件改变，开始给证据 |
| 约4—7秒 | 看清中间过程或关键差异 |
| 约7—10秒 | 结果与直接反应，或交接下一步 |

可以在一个持续镜头中完成这些变化，也可以更早给答案再展开；不要为了凑表格拆开同一个动作。后续10秒段直接接着推进，不重新放钩子。每段至少推进一项有用信息、可见因果或角色结果；观察必要过程也算推进，不追求堆满新术语。

每约2—3秒沿时间轴问：此刻正在发生什么变化？观众多理解了什么，或在观察哪个必要过程？若仅重复台词、等待或做无关反应，就删改。一个关键结果出现后留出辨认时间，再切到下一步；不硬设统一停顿长度。

每次切镜注明用途：看清作用点、揭示内部、比较前后、读取必要反应或匹配接片。避免声画争抢注意力。配音仍按自然中文约3—4字/秒粗估，并预留观察与操作时间；“加快”不意味着提高字数上限或统一倍速。

### 每段最后两秒也要有事发生

对于完整保留的10秒段，单列8—10秒的动作或图示变化，并写明尾帧到达时刻。让最后一个变化延续到接近10秒，例如道具继续产生可读位移、结果触发短反应，或图示完成与实物结果的衔接；不要8秒就摆好尾帧，之后保持姿势。接片帧优先取动作过程中的清晰瞬间，下一段从同一运动阶段继续。只有有意设计的反应停顿才短暂保持，不默认加2秒定格。

重复强调“快速”“不要停”不能取代时间轴。把慢而重复的操作压成少数清楚的接触动作，给因果留出辨认时间，再接结果和反应；不把10秒塞成难以生成的一串新任务。模型确实漏动作时，优先减少同时发生的动作、简化机位或设计匹配切镜。

若收到成片，抽查0—2秒与8—10秒，再检查关键作用过程；区分实际物体/角色/图示变化和仅有推镜、眨眼、尾巴摆动。没有新增作用的末尾应剪到最后有效变化或重生成。10秒是工具单次生成长度；裁掉等待后应报告实际成片长度，不补静止尾巴、不声称仍是原定总时长。总时长有硬要求时，用有意义的新动作或解释重新安排，不能以空镜补足。末段R<10时，只检查保留区间末端，预先声明会裁掉的R—10秒不受此要求。

## 5. 生图前的内部检查

逐项修改明确失败处后再生图，不新增用户审批：
- 开头已写出可见前后态、首次变化和结果时刻；不依赖问号、表情或台词才能指出差异，第一段提供相关证据，后续有具体待解释的原因。
- 猫的主要动作有目标、作用点和可见结果，删掉不会仍是同一段静态解说。
- 科学狂人的性格已落成有因由的操作与反应；开头能指出本期具体吸引点，不能只写亢奋表情或喊一句口号。
- 核心因果含中间过程；需要原理图时，实物部位、结构、状态与符号含义已对应，观察窗口没有被误画为真实开口，复杂生成有可用的简化方案。
- 镜头切换有用途，信息随可读变化推进，无多项无关任务同时发生。
- 时间覆盖用户的整片T，默认每段生成10秒，裁剪表与边界帧一致。
- 末段保留区间内已经完成关键结果与配音，被裁尾部不藏答案。
- 完整10秒段的8—10秒有明确变化与尾帧到达时刻；边界帧没有被误写成提前几秒停住的姿势。更新动作后若旧首尾图不匹配，须同步更新图片或明确尚未生成，不能混用成现成素材包。
- 以上仅验证脚本和静帧设计；未渲染、未看后台时，不宣称口型、动作或传播效果已验证。
